# Обработка ошибок

## Network errors

- Timeout: 10 секунд
- Retry: 1 раз автоматически
- Toast с кнопкой "Повторить"

## Exponential backoff

```
1-я попытка: сразу
2-я попытка: через 1 сек
3-я попытка: через 2 сек
4-я попытка: через 4 сек
max 30 сек
```

## Queue для offline

- Если запрос не удался → сохраняем в localStorage
- При восстановлении связи → отправляем queued запросы
- Максимум 50 запросов в очереди

## Коды ошибок

| Код | UI реакция |
|-----|-----------|
| 400 | Подсветка полей формы |
| 401 | Редирект на /login |
| 403 | "Доступ запрещён" |
| 404 | "Не найдено" |
| 500 | "Ошибка сервера, попробуйте позже" + retry toast |

# Поля анкеты (минимальный набор)

## Обязательные поля

| Поле | Тип | Описание | Варианты (для select) |
|------|-----|----------|----------------------|
| fio | text | ФИО полностью | — |
| group | text | Группа (пример: РИ-330930) | — |
| course | select | Курс обучения | 1, 2, 3, 4 |
| desired_role | select | Желаемая роль | Frontend, Backend, Аналитик |
| tech_stack | textarea | Используемые технологии | — |

## Редактирование

- Админ может добавить/убрать поля в SurveyFieldsEditor
- Тексты вопросов можно менять
- Варианты select — массив строк
- Default значения появятся автоматически

## Бэкенд совместимость

- `SurveyField` хранит тип: text/textarea/select
- `Application.surveyData` — Record<string, string>
- Порядок полей через `order`

## Тестовое задание

| Поле | Тип | Описание |
|------|-----|----------|
| test_question | text | Текст задания (создается админом) |
| test_answer | textarea | Ответ студента |
| test_status | enum | not_submitted, pending, approved, rejected |
| admin_comment | textarea | Комментарий админа при отклонении |

**Отправка теста:**
- Кнопка "Отправить на проверку" активна только при заполненном ответе
- Состояние `pending` до проверки админом
- После `approved` — можно подавать заявку
- При `rejected` — можно исправить и отправить заново

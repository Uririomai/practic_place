# Спецификация API сервиса "Практика" (v1.2)

## 1. Когорты
Когорты, все управление доступно только админу,
единственное что доступно для просмотра это список активных когорт
| Метод | Роут | Назначение | Ограничения доступа |
| :--- | :--- | :--- | :--- |
| GET | `/cohorts` | Список потоков | Только ADMIN |
| GET | `/cohorts/active` | Список потоков | Доступен всем |
| POST | `/cohorts` | Создание когорты | Только ADMIN |
| GET | `/cohorts/:id` | Детали когорты | Только ADMIN |
| PATCH | `/cohorts/:id` | Редактирование | Только ADMIN |
| DELETE | `/cohorts/:id` | Удаление | Только ADMIN. Запрещено, если есть связанные заявки |
done

## 2. Роли
Роль это позиция которя будет у человека в когорте, на каждую роль нужно отдельное тестовое задание
| Метод | Роут | Назначение | Ограничения доступа |
| :--- | :--- | :--- | :--- |
| GET | `/cohorts/:cohortId/roles` | Список ролей | Доступно всем (если сама когорта доступна всем) |
| POST | `/cohorts/:cohortId/roles` | Добавление роли | Только ADMIN |
| PATCH | `/cohorts/:cohortId/roles/:id` | Обновить роль | Только ADMIN |
| DELETE | `/cohorts/:cohortId/roles/:id` | Удалить роль | Только ADMIN |
done

## 3. Задания
Тестовое задание для приема на когорту, на каждую роль нужно отдельное задание
| Метод | Роут | Назначение | Ограничения доступа |
| :--- | :--- | :--- | :--- |
| GET | `/cohorts/:cohortId/test-tasks` | Тестовые задания | Студент (после подачи заявки) или ADMIN |
| POST | `/cohorts/:cohortId/test-tasks` | Создание задания | Только ADMIN |
| PATCH | `/cohorts/:cohortId/test-tasks/:id` | Обновить задание | Только ADMIN |
| DELETE | `/cohorts/:cohortId/test-tasks/:id` | Удалить задание | Только ADMIN |
done

## 4. Анкетирование
Параметры генерации анкеты для подачи заявки
| Метод | Роут | Назначение | Ограничения доступа |
| :--- | :--- | :--- | :--- |
| GET | `/cohorts/:cohortId/fields` | Структура анкеты | Доступно всем |
| POST | `/cohorts/:cohortId/fields` | Добавить поле | Только ADMIN |
| PUT | `/cohorts/:cohortId/fields/order` | Сортировка полей | Только ADMIN |
| PATCH | `/cohorts/:cohortId/fields/:id` | Обновить поле | Только ADMIN |
| DELETE | `/cohorts/:cohortId/fields/:id` | Удаление поля | Только ADMIN. Каскадное удаление ответов |
done

## 5. Заявки (Applications)
Сам объект прохождения практики, 
от подачи заявки до отклонения или начала прохожденяи практики, 
после чего в этом объекте будут хранится результаты прохождения
| Метод | Роут | Назначение | Ограничения доступа |
| :--- | :--- | :--- | :--- |
| POST | `/applications` | Создание заявки | Студент (1 заявка/когорта) |
| GET | `/applications` | Список заявок | Студент (свои), ADMIN (фильтр по когорте) |
| GET | `/applications/:id` | Детали заявки | Владелец или ADMIN |
| PATCH | `/applications/:id/review` | Вердикт (Approve/Reject) | Только ADMIN. REJECT требует `review_comment` |
| PUT | `/applications/:id/answers` | Сохранение анкеты | Только владелец |
done

## 6. Задачи и Отчетность (Student & Admin)
Задачи распологаются на странице практики и позволяют отслеживать результаты работы, студент может видеть все таски в когорте, но редактировать и создавать только свои, таска уникальна для (пользователь && день)
| Метод | Роут | Назначение | Ограничения доступа |
| :--- | :--- | :--- | :--- |
| GET | `/applications/:id/tasks` | Список задач | Владелец или ADMIN |
| POST | `/applications/:id/tasks` | Создание задачи | Владелец и ADMIN () |
| PATCH | `/applications/:id/tasks/:taskId` | Редактирование задачи | Владелец (если не завершено) или ADMIN |
| DELETE | `/applications/:id/tasks/:taskId` | Удаление задачи | Только ADMIN |
done

## 7. Документооборот
Для каждого студента необходимо подготавливать документы, а именно: тутульный лист, дневник практики, отзыв руководителя (как минимум, надо бы сделать расширяемость)
Шаблоны загружаются админом для каждой когорты

| Метод | Роут | Назначение | Ограничения доступа |
| :--- | :--- | :--- | :--- |
| GET | `/cohorts/:cohortId/document-templates` | Список шаблонов когорты | Только ADMIN |
| POST | `/cohorts/:cohortId/document-templates` | Загрузить шаблон | Только ADMIN |
| PATCH | `/cohorts/:cohortId/document-templates/:id` | Обновить шаблон и требования (`requirements`) | Только ADMIN |
| DELETE | `/cohorts/:cohortId/document-templates/:id` | Удалить шаблон | Только ADMIN |
| GET | `/applications/:id/document-data` | Получить JSON с данными документов | Владелец или ADMIN |
| PATCH | `/applications/:id/document-data` | Изменить JSON с данными | Только владелец (или ADMIN при необходимости) |
| PUT | `/applications/:id/files/report` | Загрузить отчет | Только владелец |
| GET | `/applications/:id/files/report` | Скачать отчет | Владелец(после поддверждения) или ADMIN |
| PATCH | `/applications/:id/files/report/status` | Изменить статус отчета (`PENDING`/`APPROVED`/`REJECTED`) | Только ADMIN |
| GET | `/applications/:id/documents` | Список документов с признаком `available` и причиной недоступности | Владелец или ADMIN |
| GET | `/applications/:id/documents/:templateId` | Сгенерировать и скачать документ | Владелец или ADMIN |

# UI Standards

## Библиотеки

### shadcn/ui
Базовые компоненты:
- Button — все кнопки
- Input — текстовые поля
- Form — обёртка для форм
- Table — таблицы
- Dialog/Sheet — модальные окна
- Tabs — переключение вкладок
- Card — карточки
- Badge — индикаторы статуса
- Select — выпадающие списки
- Calendar — выбор дат

### date-fns
- Форматирование дат в UI
- Вычисление недель и дней
- Совместимость с серверным кодом

### React Hook Form + Zod
- Валидация форм на клиенте
- Схемы валидации в одном месте
- Debounce + автосохранение

## Паттерны интерфейса

### Формы

1. Схема Zod с конкретными правилами
2. useForm с resolver
3. FormField для каждого поля
4. Кнопка disabled при isSubmitting
5. a11y: aria-label, aria-describedby для ошибок

### Таблицы

- Заголовки сортируемые (по клику)
- Статусы — цветные Badge
- Пагинация (есто 20 элементов на странице)
- Поиск по имени (полный текст)
- На mobile: горизонтальная прокрутка

### Модальные окна

- Desktop: Dialog (центр)
- Mobile (< 768px): Sheet (сверху)
- ESC + overlay click закрывают
- Focus trap внутри окна

## Цвета статусов

```
pending:    #fef3c7 (bg) + #92400e (text) — жёлтый (ожидание)
approved:   #dcfce7 (bg) + #166534 (text) — зелёный (одобрено)
rejected:   #fee2e2 (bg) + #991b1b (text) — красный (отклонено)
not_submitted: #f3f4f6 (bg) + #374151 (text) — серый (не отправлен)
```

## Состояния тестового задания

| Состояние | Иконка | Описание |
|-----------|--------|----------|
| `not_submitted` | ⏱ | Тест есть, но студент не отправил |
| `pending` | ⏳ | Отправлен, ожидает проверки |
| `approved` | ✓ | Одобрен, можно подавать заявку |
| `rejected` | ✗ | Не прошёл, можно исправить |

## Адаптивность

- Mobile (sm): одна колонка, Sheet модальные, скролл таблиц
- Tablet (md): два столбца в сетке задач
- Desktop (lg): полные таблицы, Dialog модальные, виртуальный скролл

## Accessibility (a11y)

### Элементы

- Все интерактивные элементы имеют aria-label
- Форма: aria-describedby на ошибки
- Tabindex последовательный

### Клавиатура

- Tab/Shift+Tab навигация
- ESC закрывает модальные окна
- Enter submitит формы

## Лучшие практики

- Компоненты переиспользуемые: Button, Input, Badge
- Состояния UI предсказуемы: loading/error/empty/success
- Формы с валидацией сразу
- Адаптивность — флекс сетка, нет отношения "desktop-only"
- Accessibility — WCAG 2.1 AA

# Admin Module

## Назначение модуля

Админ-панель управляет всем процессом практики в контексте выбранной когорты. Админ "проваливается" в когорту и видит только её данные.

## Архитектура

### Выбор когорты

- При входе админ выбирает когорту из списка
- Выбор сохраняется в CohortContext + sessionStorage
- При обновлении страницы восстанавливается последний выбор
- Автовыбор самой новой когорты если в sessionStorage нет

### Вкладки админ-панели

1. **Заявки** — список кандидатов, одобрение/отклонение
2. **Документы** — статус документов студентов
3. **Задачи** — все задачи с группировкой
4. **Управление** — создание когорты, настройка анкеты

### Смена роли практиканта

- Инлайн редактирование в таблице заявок
- Клик на ячейку "Роль" → выпадающий список
- PATCH `/api/admin/applications/:id` (частичное обновление)
- Optimistic update + undo в течение 3 секунд

- Инлайн-редактирование роли
- Toast подтверждения после изменения

- Таблица со студентами и индикаторами документов
- Пагинация 25 на странице
- Поиск по ФИО

- Редактор полей анкеты при создании когорты
- Превью формы в реальном времени

### `src/modules/admin/components/ReviewForm.tsx`
- Форма отзыва админом
- Автосохранение не включено (должно быть открыто и заполнено)

- `/app/(admin)/tasks/page.tsx` — задачи

## Лучшие практики

- Админ работает в контексте одной когорты
- Инлайн редактирование вместо модальных окон
- Пагинация + поиск для больших списков
- Undo для критических действий (смена роли)

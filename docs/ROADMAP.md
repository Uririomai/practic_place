# Дорожная карта проекта «Практика»

## Зависимости проекта

### Основные:
```bash
npm install next@14 react@18 react-dom@18 typescript@5
npm install tailwindcss@3 postcss autoprefixer
npm install zod react-hook-form
npm install date-fns
npm install @radix-ui/react-* (через shadcn/ui)
```

### shadcn/ui компоненты:
```bash
npx shadcn-ui@latest add button input form dialog sheet tabs table card badge select
npx shadcn-ui@latest add calendar popover command avatar dropdown-menu
```

### Dev зависимости:
```bash
npm install -D eslint prettier eslint-plugin-react eslint-plugin-react-hooks
npm install -D playwright @playwright/test
npm install -D @types/node @types/react
```

## ЭТАП 5.1: Задачи и прогресс (полная реализация по ТЗ) ✅

### Контекст:
ТЗ п. 10 — Модуль 7. Задачи и прогресс. Текущая реализация покрывает базовую функциональность (сетка, CRUD), но не хватает ключевых элементов: привязка к датам когорты, показ всех участников, отображение ролей и времени обновления.

### Задачи — Сетка по датам когорты:
- [x] Привязать сетку к `cohort.practiceStart` / `cohort.practiceEnd` вместо текущей даты
- [x] Ограничить навигацию по неделям в пределах практики (нельзя листать за пределы когорты)
- [x] Определить стартовую неделю (ближайшая к сегодняшнему дню или первая практики)
- [x] Добавить отображение общего прогресса (например: «Неделя 3 из 8»)

### Задачи — Видимость и участники:
- [x] Добавить чекбокс «Показать всех» для переключения между своими задачами и задачами всех участников
- [x] Загружать список участников когорты (api.cohortParticipants.list()) с ФИО и ролями
- [x] Отображать ФИО + роль участника рядом с его задачами в режиме «Показать всех»
- [ ] Админ по умолчанию видит всех участников (чекбокс включён) — реализуется в ЭТАПЕ 6

### Задачи — Карточка задачи:
- [x] Отображать `updated_at` в карточке (относительное время: «2 часа назад», «вчера»)
- [x] Поле «Что было сделано» как отдельное от «Название» (ТЗ: 3 поля: название, что сделано, артефакт)
- [x] На mobile (< 768px) использовать Sheet вместо Dialog для карточки

### Задачи — API и данные:
- [x] Расширить API: добавить `GET /api/cohort-participants?cohortId=` для списка участников
- [x] Добавить мок-хендлер для участников когорты
- [x] Обновить фикстуры: добавить участников с ролями, расширить карточки задач

### Задачи — UX:
- [x] Optimistic update с rollback при ошибке сохранения
- [x] Пустое состояние: «Эта неделя вне периода практики»
- [x] Skeleton loader при загрузке карточек
- [x] Группировка задач по участникам в режиме «Показать всех»

**После выполнения:** Полноценный модуль задач по ТЗ — сетка по датам когорты, показ всех участников с ролями, updated_at, 3 поля карточки

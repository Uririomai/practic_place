# Модуль 7. Задачи и прогресс

## Назначение модуля

Модуль задач реализует ежедневный отчёт практикантов о выполненной работе. Это не канбан-доска — карточки не перетаскиваются, это фиксированная сетка ячеек для заполнения информации по дням практики.

## Архитектура

### Сетка по неделям

**Источник дат:**
- Даты начала/окончания практики берутся из настроек **когорты** (`cohort.practiceStart`, `cohort.practiceEnd`)
- Сетка строится по дням в рамках этих дат, без учёта суббот и воскресений (только пн-пт)
- Недели вычисляются через `date-fns` (`startOfWeek`, `endOfWeek`, `eachDayOfInterval`, `isWeekend`)

**Отображение:**
- Пагинация по неделям (стрелки ← →)
- Текущая неделя определяется по `practiceStart` когорты (или ближайшая к сегодняшнему дню)
- Даты передаются как строки `YYYY-MM-DD` (ISO format) — без времени, чтобы исключить timezone-баги

### Видимость задач

**По умолчанию** практикант видит только свои задачи.

**Чекбокс «Показать всех»** переключает отображение на список всех участников когорты:
- Каждый участник отображается со своим ФИО и ролью (назначенной админом после одобрения заявки)
- Разделения по трекам нет — роль просто подписывается рядом с ФИО
- Админ по умолчанию видит всех участников

### Карточка задачи

**Поля:**
| Поле | Описание |
|------|----------|
| Название | Краткое описание задачи |
| Описание | Что было сделано (текст) |
| Ссылка на артефакт | Единое поле-ссылка: GitHub, Figma, скриншоты и т.п. (без файлового хранилища) |

**Особенности:**
- Клик/плюсик по ячейке дня открывает модальное окно создания/редактирования
- Практикант может самостоятельно создавать и заполнять карточки — не обязан ждать задачу от куратора
- При сохранении фиксируется `updated_at` — время последнего обновления видно в интерфейсе
- Optimistic update при сохранении (UI обновляется до ответа сервера, с rollback при ошибке)

### Структура данных

**TaskCard:**
| Поле | Тип | Описание |
|------|-----|----------|
| `id` | UUID | Идентификатор карточки |
| `user_id` | UUID | Ссылка на пользователя |
| `cohort_id` | UUID | Ссылка на когорту |
| `date` | String | Дата в формате `YYYY-MM-DD` |
| `title` | String | Название задачи |
| `description` | String | Описание (что было сделано) |
| `artifact_link` | String? | Ссылка на артефакт |
| `updated_at` | DateTime | Время последнего обновления |

**API-эндпоинты:**
| Метод | Путь | Описание |
|-------|------|----------|
| GET | `/api/task-cards?cohortId=&week=` | Карточки за неделю |
| POST | `/api/task-cards` | Создание карточки |
| PUT | `/api/task-cards/:id` | Обновление карточки |

## Компоненты

### `components/cabinet/TasksTab.tsx`
Главная страница вкладки «Задачи».
- Сетка по неделям (Mon-Fri)
- Навигация по неделям (← →)
- Чекбокс «Показать всех» для переключения между своими задачами и задачами всех участников
- Список участников с ФИО и ролями (при включённом «Показать всех»)
- Клик по ячейке → модальное окно создания/редактирования

### Модальное окно задачи
- Поля: название, описание (что сделано), ссылка на артефакт
- На mobile (< 768px) использует Sheet вместо Dialog
- Optimistic update при сохранении

## Мок-данные

| Эндпоинт | Фикстура |
|----------|----------|
| `GET /api/task-cards` | `mockTaskCards` — список карточек с датами, заголовками, описаниями, ссылками |
| `POST /api/task-cards` | Возврат созданной карточки с `id` и `updated_at` |
| `PUT /api/task-cards/:id` | Возврат обновлённой карточки |

## Лучшие практики

- Даты без времени — исключаем timezone-баги
- `date-fns` для работы с датами (parseISO, format, eachDayOfInterval)
- Пагинация по неделям вместо длинного списка всех дней практики
- Responsive UI: Sheet на mobile, Dialog на desktop
- Optimistic update с rollback при ошибке
- `updated_at` всегда отображается для прозрачности

## Связь с другими модулями

- **Когорты (модуль 1):** даты practice_start/end определяют диапазон сетки
- **Роли (модуль 4.3):** роль практиканта отображается рядом с ФИО в режиме «Показать всех»
- **Заявки (модуль 3):** задачи видны только после одобрения заявки в текущей когорте
- **Админ-панель (модуль 6.3):** админ видит задачи всех участников когорты по умолчанию

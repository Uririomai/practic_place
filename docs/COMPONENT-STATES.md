# Состояния компонентов

## Состояния тестового задания

| Статус | Иконка | Цвет | Текст | Действие |
|--------|--------|------|-------|----------|
| `not_submitted` | ⏱ | gray | "Тест не отправлен" | Кнопка "Отправить" |
| `pending` | ⏳ | yellow | "Тест на проверке" | Индикатор "ожидание" |
| `approved` | ✓ | green | "Тест одобрен" | Переход к заявке |
| `rejected` | ✗ | red | "Тест не прошёл" | Кнопка "Отправить заново" |

## Состояния UI (4 статуса)

| Состояние | Компонент | Поведение |
|-----------|-----------|-----------|
| Loading | Skeleton или Spinner | Тёмно-серый placeholder |
| Error | Alert + кнопка retry | Красный фон, иконка alert-circle |
| Empty | Текст + кнопка действия | "Пока ничего не добавлено" |
| Success | Список/форма | Активный контент |

## Toast-сообщения

| Событие | Сообщение | Продолжительность |
|---------|-----------|-------------------|
| Test submitted | "Тест отправлен на проверку" | 3 сек |
| Test approved | "Тест одобрен! Можно подавать заявку" | 5 сек |
| Test rejected | "Тест не прошёл. Проверьте ответы" | 5 сек + редактирование |
